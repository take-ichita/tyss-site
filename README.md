# 株式会社TYSS コーポレートウェブサイト

## 📋 プロジェクト概要

株式会社TYSSの東南アジア向け輸出ビジネスを中心としたコーポレートウェブサイトです。
物販事業とAI・ITソリューションの両軸で事業展開する企業の魅力を、プロフェッショナルなデザインで表現しています。

## 🎯 プロジェクトの目的

- 東南アジア輸出ビジネスを前面に打ち出した企業ブランディング
- オリジナル商品プロデュース(食品や日用品などのOEM開発・販売、クラウドファンディング活用)の紹介
- 自社プロダクト「HANABI」「HAKONAVI」の開発事業の紹介
- AI業務効率化コンサルティング(経営者層向け・物販に限らず一般業務も対応)の訴求
- システム開発・コンサルティング(開発+販売コンサルの一体提供)の訴求
- Claude Partner Network参加による技術的信頼性の提示
- 問い合わせ獲得とリード創出

## 🚀 公開方法（GitHub Pages）

1. `main`ブランチへコミット・プッシュする
2. リポジトリの「Settings」→「Pages」を開く
3. Sourceで「Deploy from a branch」を選択する
4. Branchを`main`、フォルダを`/(root)`に設定して保存する
5. GitHub PagesのURLが発行されるまで待つ

`index.html`がリポジトリの最上位にあることを必ず確認してください。

## 🔧 カスタマイズガイド

### 企業情報の変更
**index.html** の以下のセクションを編集(行番号はズレるためセクションIDで検索してください)：
- ヒーローセクション: `<section class="hero" id="home">`
- 事業内容: `<section class="business-overview" id="business">`
- お問い合わせ情報: `<section class="contact" id="contact">`

### カラースキームの変更
**css/style.css** の冒頭にある`:root`変数を編集：
```css
:root {
    --primary-color: #FF6B35;
    --secondary-color: #004E89;
    /* その他のカラー変数 */
}
```

### お問い合わせフォーム(Googleフォーム)の運用
HANABI公式サイトと共通の既存Googleフォームを流用しています(新規作成は不要)。
- 短縮URL: https://forms.gle/Wei9GRR1WXy8iVwd7
- 実体: https://docs.google.com/forms/d/e/1FAIpQLSdQ6FRuU-FRfHb_FT2XPSANoUdklJIAQmSeiHeDRqc6jA3OMA/viewform

コーポレートサイト兼用にするための推奨編集(Googleフォームの編集画面で。**既存の回答データやURLには影響しません**):
1. タイトル「HANABI問い合わせフォーム」→「株式会社TYSS お問い合わせフォーム」に変更
2. 説明文に「HANABI・HAKONAVIのほか、AI業務効率化やシステム開発のご相談もこちらから」と追記
3. 「お問い合わせ種別」(プルダウン)を追加: HANABI・HAKONAVIについて / AI業務効率化のご相談 / システム開発・コンサルティング / 東南アジア輸出・Shopee販売 / その他

将来コーポレート専用フォームに分離する場合は、**index.html** 内のお問い合わせセクションにあるCTAボタンの `href` を新しいフォームURLに差し替えてください(HTMLコメントで目印あり)。

### 独自ドメイン移行時のSEO設定差し替え
現在のSEOタグは GitHub Pages のURL( https://take-ichita.github.io/tyss-site/ )で設定しています。
独自ドメインへ移行する際は、以下の箇所をすべて新ドメインに差し替えてください(各ファイルに `TODO` コメントで目印あり):

1. **index.html**: `<link rel="canonical">`、OGPの `og:url`・`og:image`、JSON-LD内の `url`
2. **robots.txt**: `Sitemap:` のURL
3. **sitemap.xml**: `<loc>` のURL
4. GitHub リポジトリの「Settings」→「Pages」でカスタムドメインを設定
5. 移行後、Google Search Console にサイトを登録して sitemap.xml を送信
